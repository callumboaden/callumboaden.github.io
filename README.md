## Notes

- Built with plain HTML, CSS, and minimal JavaScript.
- Designed to run directly from the repository root on GitHub Pages.
- No framework, package manager, build step, or external CSS library is required.
- External project/contact links open in a new tab with `rel="noopener noreferrer"`.

The current resume PDF and project preview images are local placeholder assets. Replace the files in `assets/` with final resume/artwork when available.
